# Introduction au langage TypeScript et au framework NestJS

> ⚠️ **Ce dépôt n'est pas un projet logiciel.** Il n'y a ici ni application à installer, ni
> package à publier, ni issues de code à corriger : c'est le **support d'un cours**, rédigé
> pour des étudiants découvrant TypeScript puis le framework NestJS.

## 📖 Lire le cours

Le cours se lit en ligne, à cette adresse :

**👉 [https://stahe.github.io/typescript-nestjs-sept-2026/](https://stahe.github.io/typescript-nextjs-sept-2026/)**

Aucune installation n'est nécessaire pour le lire : un simple navigateur suffit.

## 🎯 À qui s'adresse ce cours ?

Ce cours s'adresse à des étudiants qui n'ont **aucune connaissance préalable** de
TypeScript ni de NestJS. Il part des fondamentaux du langage TypeScript pour aller
progressivement jusqu'à la construction d'applications complètes avec le framework
NestJS, à travers de nombreux exemples de code entièrement commentés, ligne par ligne.

## 📚 Plan du cours

Le cours est organisé en grandes parties :

1. **Les fondamentaux de TypeScript** — installation de l'environnement de travail,
   syntaxe du langage, typage statique, programmation orientée objet.
2. **Les fonctions HTTP de TypeScript** — construire un serveur HTTP et un client
   HTTP en TypeScript pur, avant l'introduction de tout framework.
3. **L'accès aux bases de données** — trois approches comparées : le pilote natif
   `mysql2`, l'ORM [TypeORM](https://typeorm.io/), puis l'ORM [Prisma](https://www.prisma.io/).
4. **Le framework NestJS** — introduction au framework, son architecture MVC, la
   gestion des requêtes (actions/réponses), la couche modèle, et l'accès aux données
   avec NestJS.
5. **Une étude de cas complète** — le portage, en NestJS, d'un serveur de calcul de
   l'impôt sur le revenu initialement écrit en PHP : contrôleurs, couches DAO et
   métier, gestion de session, et construction des pages HTML avec des gabarits EJS.
